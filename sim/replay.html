Every model on the simulated rig, and the same knock

Each model wrote this firmware against the simulator, from an empty folder, with no hardware involved. It's the best run so far from the S1 sweep, which is still running, on the simulator build that run used. All of them get up at 6 s and the same knock on the rod at 26 s, 3 rad/s. Margin is the largest knock that run recovers from in both directions, of 0.5, 1, 2, 3, 4 and 6. This is a rerun made for this page, not the judge's trials, though the levels on the cards are the judge's. The marks on the timeline jump to that moment.
